# Original self-study assessment

Not an official NUS rubric.

## Why is zero-filling missing hours potentially misleading?

It changes the mean and encodes missingness as a real zero. Compare missing-data assumptions and document the policy.

## What should be fitted only on training data in later modules?

Imputation statistics, scalers, feature selection and any data-dependent transforms.

## Build task

Add a reusable validation function; test an empty file, duplicate columns, out-of-range scores and a fully missing numeric column.

## Suggested scoring, 100 points
- Reproducible clean run and tests: 25
- Correct mechanism and explanation: 25
- Evaluation with a held-out set or explicit mechanism checks: 20
- Failure cases, provenance and limits: 20
- Readable demo and documentation: 10

Pass suggestion: 70, with no fabricated results, private-data exposure or unsupported production claims. This is a self-study convention.
